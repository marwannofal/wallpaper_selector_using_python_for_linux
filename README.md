# Desktop Wallpaper Selector

# Requirements:

1. Python 3
2. Linux (Ubuntu GNOME or any GNOME-based desktop environment)
3. An active internet connection (for retrieving sunrise/sunset times)

# Installation:

1. Clone the repository or download the script.
2. Ensure you have Python 3 installed:
    python3 --version
3. Make the script executable:
    chmod +x wallpaper_selector.py

# Usage:
Run the script with your latitude and longitude as arguments:
    python3 wallpaper_selector.py <latitude> <longitude>
